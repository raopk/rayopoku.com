# Chartbuilder (built bundle)

This folder holds only the compiled `build/` output of
[Quartz Chartbuilder](https://github.com/Quartz/Chartbuilder), used by
`chartbuilder.html` on this site. The source tree, tests and npm
manifests were removed because the site never runs them and they were
the sole source of Dependabot alerts. See `LICENSE` (MIT, Quartz).
